# Yandex Disk Integration 🎓

Учебный проект, демонстрирующий работу с REST API (Cataas и Яндекс.Диск).

## 💡 Что я изучила, делая этот проект
- Объектно-ориентированное программирование (классы, наследование)
- Работу с `requests.Session()` для эффективных HTTP-запросов
- Двухэтапную загрузку файлов через API
- Обработку HTTP-ошибок через `raise_for_status()`
- Визуализацию прогресса через `tqdm`

## 🛠 Технологии
- Python 3.x
- requests
- tqdm
- REST API (Cataas, Yandex Disk)
